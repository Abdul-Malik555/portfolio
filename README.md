# Abdul Saboor Malik — AI-Enhanced Digital Portfolio

Premium multi-page static portfolio built with separate HTML files. Each page keeps its CSS and JavaScript embedded in the same HTML file; no framework or external stylesheet is required.

## Pages
- `index.html` — Home
- `about.html` — About Abdul Saboor Malik
- `education.html` — Education & Learning
- `skills.html` — Skills & Expertise
- `experience.html` — Professional Experience
- `services.html` — Services & Solutions
- `projects.html` — Selected Projects
- `case-studies.html` — Detailed Case Studies
- `blog.html` — Insights / Blog hub
- `contact.html` — WhatsApp-first Contact

## Blog workflow
Create any new article as a root-level HTML file, for example `blog-ai-automation.html`, with its own embedded CSS and JavaScript. Then add one card to `blog.html` and set its link to that filename.

Example:
```html
<a href="blog-ai-automation.html">Read Article →</a>
```
